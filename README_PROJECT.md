# E-commerce Customer Analysis

## Objective
Analyze customer purchasing patterns, spending, and activity status using Python, Pandas, and Matplotlib.

## Dataset
`data/ecommerce_customers.csv` is a small **synthetic sample dataset created for practice**. It is not real company or customer data.

## Questions explored
- How many customers are Active, At Risk, or Inactive?
- What is the average order value for each customer status?
- Which region has the highest total customer spend?

## Tools
- Python
- Pandas
- Matplotlib

## Run locally
1. Install Python.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python ecommerce_analysis.py`

The script prints summary tables and saves charts in the `outputs` folder.
